## ✨ 这是什么

这是一个跑在自家服务器上的「亲子留言信箱」：

- 孩子用 **小智 AI 音箱**（xiaozhi.me 智能体）说话，就能给妈妈留言——不用打字、不用手机；
- 妈妈在**企业微信**里收到机器人秒级提醒，随手回一句文字；
- 孩子随时对小智说"读留言"，就能听到妈妈的话；
- 每天凌晨，AI 会把当天的亲子对话总结成一段温馨的小作文，妈妈在企微里发个指令就能回看。

适合场景：上班父母与在家孩子/老人的日常陪伴、异地家庭、想给孩子的 AI 音箱加一点"家的温度"。

## 🌟 功能一览

| 模块 | 功能 |
|---|---|
| 🎙️ 语音留言 | 孩子对小智说"给妈妈留言，说……"，留言入库并**秒级推送**企微群 |
| 📮 语音读信 | "读留言"读取最新未读留言（按时间正序），读完自动标记已读、绝不重复 |
| 🤖 企微机器人 | 官方 SDK **WebSocket 长连接**，无需公网回调、无需白名单、无需备案 |
| 📊 AI 每日总结 | 每天 00:05 自动调用 MiniMax 生成当日对话总结（15 字短总结 + 完整总结） |
| 📱 Web 控制台 | 账号登录（15 天免登录）：设备管理 / 对话记录 / AI 设置 / 企微配置 |
| 🔌 多设备 | 多台小智设备绑定不同企微机器人，各自独立通知 |
| 💬 企微小指令 | `查信息 9.15` 查历史总结、`查未读` 看孩子没听的留言、`@帮助` 使用说明 |
| 🛡️ 安全 | 密钥隔离不入库、PBKDF2 密码存储、企微 Secret 掩码显示、token 15 天自动过期 |

## 🏗️ 系统架构

```
孩子说话 → 小智设备(ESP32) → 小智云端(ASR + LLM + TTS)
                                   │ LLM 判断需要调用工具（MCP 协议）
                                   ▼
                 MCP 接入点 wss://api.xiaozhi.me/mcp/?token=...
                                   ▲ 本服务主动反向连接（JSON-RPC 2.0）
                                   │
                   ┌───────────────┴────────────────┐
                   │      亲子信箱服务 (本项目)        │
                   │                                │
                   │  · MCP 工具：留言 / 读信 / 未读数  │
                   │  · 企微机器人长连接(官方SDK)       │──── 企业微信
                   │  · Web 控制台（FastAPI）          │    （群通知 + 回信）
                   │  · MiniMax 每日总结 + 定时任务     │
                   └───────────────┬────────────────┘
                                   ▼
                        SQLite（留言/设备/总结/账号）
```

> 小智云端是 MCP **客户端**，本项目作为 MCP **服务器**主动反向连接它的接入点，无需在路由器开任何入站端口。

## 🚀 快速开始

### 前置准备

| 需要 | 获取方式 |
|---|---|
| 小智 MCP 接入点 | 登录 [xiaozhi.me](https://xiaozhi.me) 控制台 → 智能体配置页右下角复制（`wss://api.xiaozhi.me/mcp/?token=...`） |
| 企业微信 | 注册企业微信，管理后台 → 安全与管理 → 管理工具 → **智能机器人** → 创建机器人 → API 模式 → 连接方式选 **"使用长连接"** → 保存后生成 Bot ID 和 Secret |
| MiniMax APIKey（可选） | [MiniMax 开放平台](https://platform.minimaxi.com) 创建，用于每日总结；不填不影响留言功能 |

### 安装运行

```bash
git clone https://github.com/xinghuoseo/xiaozhi-mailbox.git
cd xiaozhi-mailbox
python3 -m venv venv
venv/bin/pip install -r requirements.txt
```

创建 `.env`：

```ini
MCP_ENDPOINT=wss://api.xiaozhi.me/mcp/?token=你的接入点token
DB_PATH=/path/to/mailbox.db
```

启动：

```bash
venv/bin/uvicorn main:app --host 127.0.0.1 --port 8300
```

打开 `http://127.0.0.1:8300`，默认账号 **admin / xiaozhi123**（首次登录后请立即修改密码）。

### 首次配置（控制台四步走）

1. **设备** → 添加设备 → 粘贴 MCP 接入点 → 状态变绿点即已连上小智云端；
2. **企微配置** → 添加配置（Bot ID + Secret）→ 点"连通"验证 → 把机器人拉进家庭群 → 群里 @它 发条消息自动记录群会话；
3. **AI 设置** → 填入 MiniMax APIKey → 点"连通测试"；
4. （可选）设备编辑里把设备绑定到指定机器人；把智能体的角色设定补一句：*提到妈妈、留言、回信时必须调用工具，不要编造留言内容*。

## 🖥️ 控制台功能

- **设备**：多台小智设备管理，连通测试（MCP 握手验证），绑定企微机器人；
- **记录**：左侧按天聚合（日期 + 条数 + AI 15 字总结），右侧聊天气泡展示当天对话，底部可直接以妈妈身份发送留言；总结可随时手动重新生成；
- **AI 设置**：MiniMax APIKey / 模型名 / 接口地址均可配置，带连通测试；
- **企微配置**：多套机器人配置，Secret 掩码回显，连通测试直达企微网关。

## 🧩 MCP 工具（对小智设备开放）

| 工具 | 触发话术示例 | 说明 |
|---|---|---|
| `mailbox.send_message_to_mom` | "给妈妈留言，说……" | 入库 + 推送企微，成功标记已送达 |
| `mailbox.read_messages_from_mom` | "读留言""查信箱" | 读未读留言并标记已读（时间正序） |

扩展新工具三步：`app/tools/` 写函数（返回 `{"success": bool, "result": "适合朗读的中文短句"}`）→ 注册进 `app/tools/__init__.py` → 重启。

## ⏰ 每日总结机制

```
每天 00:05（服务启动时会自动补跑遗漏的日期）
  ├─ 取前一天全部对话（孩子留言 + 妈妈回信，按时间正序）
  ├─ 调用 MiniMax 生成 short（≤15字）+ full（约150字）
  └─ 写入 daily_summaries（失败自动标记，可手动重试）
```

## ❓ 常见问题

<details>
<summary>群聊里不 @机器人 的消息收不到？</summary>
是的，这是企业微信官方的隐私规则：群聊中机器人只能收到 @ 它的消息，无法关闭。机器人<b>单聊</b>不需要 @，全部消息都会接收。建议把机器人星标置顶，用单聊回信最顺手。
</details>

<details>
<summary>为什么留言有时说"妈妈那边暂时没通知到"？</summary>
推送企微群时机器人不在线（比如服务器刚重启还没连上）。留言已安全入库，稍后机器人在线时重复一次留言即可。
</details>

<details>
<summary>MCP 接入点 token 泄露了怎么办？</summary>
到 xiaozhi.me 控制台重新生成接入点，然后在控制台"设备"里编辑设备粘贴新地址保存，会自动重连。
</details>

<details>
<summary>服务器重启后需要重新登录控制台吗？</summary>
不需要。登录 token 持久化在数据库中，15 天内重启服务、刷新页面都保持登录。
</details>

## 🛡️ 安全说明

- `.env`（含 MCP 接入点）与 `mailbox.db` 已通过 `.gitignore` 排除，**永不入库**；
- 登录密码使用 PBKDF2-SHA256 加盐哈希；
- 企微机器人 Secret 在控制台仅显示掩码；
- 建议将控制台部署在内网或加 IP 白名单。
