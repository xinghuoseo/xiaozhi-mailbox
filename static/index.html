使用说明
创建机器人：企微管理后台 → 安全与管理 → 管理工具 → 智能机器人 → 创建机器人 → API 模式创建 → 连接方式选 "使用长连接" → 保存后页面生成 Bot ID 和 Secret，填到这里 → 点"连通"验证 → 把机器人拉进家庭群。
日常使用：孩子对小智说"给妈妈留言…"，群里马上收到机器人提醒；在群里 @机器人 发文字（或在机器人单聊里直接发，不用@）就是给孩子回信，孩子对小智说"读留言"就能听到。
小指令：发 查信息 9.15 看当天对话总结（不写年份默认今年）；发 @帮助 看使用说明。
小提醒：企微官方规则，群聊里机器人只能收到 @ 它的消息；设备列表里可以把设备绑定到不同机器人。
